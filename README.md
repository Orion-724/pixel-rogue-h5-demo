# 像素拼装肉鸽 · 手机横屏 H5 Demo

基于已有浏览器玩法原型扩充的手机横屏构筑战斗 Demo，用于展示从玩法原型到移动端可玩展示版本的迭代过程。

使用原生 **JavaScript / Canvas 2D / HTML / CSS**，不依赖游戏引擎、构建工具或运行时第三方库。当前重点是构筑交互、触屏适配与最低限度统一美术，而非完整商业游戏。

- **源码仓库**：[Orion-724/pixel-rogue-h5-demo](https://github.com/Orion-724/pixel-rogue-h5-demo)
- **在线试玩**：尚未完成部署与外网验证；部署完成后在此补充实际地址。
- **推荐环境**：手机 Chrome，横屏游玩；桌面支持键盘和鼠标。

## 玩法与操作

选择词条并放入五个膛位的“扳机”和“膛”端点，组合触发方式与攻击效果，在波次战斗中观察不同构筑的表现。可使用火、风、冰等元素与武器词条；本 H5 派生版保留原型玩法规则，不以移动适配为由重调数值。

| 操作 | 手机 | 桌面 |
|---|---|---|
| 移动 | 左侧八方向触屏摇杆 | WASD / 方向键 |
| 主动释放火触发 | 达到热度条件时按右侧“火”按钮 | 达到条件时按空格 |
| 选卡、装填 | 点卡再点兼容端点，或拖放 | 鼠标点选 / 拖放 |
| 移动或互换已装词条 | 拖向兼容的空槽或已占用端点 | 鼠标操作 |
| 结束后重新开始 | 游戏结束界面操作后回菜单再开始 | 同左 |

攻击和效果按既有触发规则运行；“火”按钮是单次按下请求，不是长按连发。竖屏显示横屏提示，当前未实现全屏入口。

## 本版展示重点

- **移动端输入**：多点触控、摇杆与主动释放并行、输入取消/失焦清理，保留桌面输入路径。
- **构筑交互**：点选与拖拽双路径、兼容目标判定、已装词条移动与互换，以及防止旧选择轮次重复提交的引用身份校验。
- **静态美术接入**：玩家、普通怪、精英与 Boss 的角色素材；按血量变化的轮廓、濒死压暗闪烁、玩家受击反馈与低对比地面。
- **资源与绘制**：加载失败回退、加载结算与缓存构建、预生成绘制变体，减少重复绘制处理。
- **验证方式**：离线逻辑回归、浏览器真实 Canvas 像素/绘制与输入检查、指定 Android手机试玩；不将桌面仿真当成真机性能测试。

## 项目来源、贡献与开发方式

本仓库为既有原型 **0.0.1** 的 H5 展示派生版，不是从零独立重写的另一款游戏；原型版本独立保留。本版主要扩充手机输入、构筑交互、布局与静态美术集成，维持原玩法与逻辑坐标。

项目开发使用了 **OpenAI Codex 等 AI 辅助工具**，协助方案拆解、代码实现、测试和文档。项目负责人负责目标与需求取舍、方案确认、素材方向选择，以及真机试玩和体验验收。代码与测试包含 AI 辅助产出，不宣称全部为无辅助独立手写。

角色与地面采用 **0x72 的 DungeonTileset II**，并保留作者及贡献者致谢；不是本项目原创绘制的角色美术。素材来源、许可依据与派生处理见 [CREDITS.md](CREDITS.md)。

## 本地运行

将本目录作为静态网站运行，打开 /index.html。没有构建或 npm 安装步骤。

例如，**如果电脑已安装 Python 3**，可以在项目目录运行以下命令，仅绑定本机回环：

~~~sh
python -m http.server 8000 --bind 127.0.0.1
~~~

然后打开 http://127.0.0.1:8000/index.html；结束后在终端按 Ctrl+C。这只是通用本地预览方式，不代表已配置公网或手机局域网访问。未安装 Python 时无需为本项目强行安装，可使用已有静态网站工具。

## 已验证范围与限制

- 指定设备：**iQOO Neo10 Pro / OriginOS 6 / Android Chrome**。用户完成一次完整流程试玩，并反馈旋转、切后台和遮挡无问题；使用低伤害构筑观察后确认低血闪烁正常。
- 电脑浏览器：Chrome 156 Headless；移动视口与触摸仿真支持本机检查，不能替代手机实测。
- 本次手机 Chrome 的精确版本、逐场景耗时和全量操作遥测未记录；不宣称全机型或所有浏览器兼容。
- 角色使用单帧静态素材，**不会随移动方向转身或播放动作动画**；当前属范围内表现。全屏、音效和扩展动画未实现。
- **未完成量化性能验收**：没有正式 FPS/帧时间、长时间发热和多设备负载数据。第 7 波总计 30 怪分批生成，不等于已验证 30 怪同屏。
- 当前是作品集 Demo，不是生产级或商业完整产品；线上部署和正式试玩入口还需单独验证。
